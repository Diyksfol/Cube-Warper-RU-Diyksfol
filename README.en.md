# Cube Warper 1.15: Russian Localization

Russian quests, guides and thousands of names from multiple mods in the pack.

A Russian localization add-on for Cube Warper 1.15 on Minecraft 1.20.1 Forge, prepared by Diyksfol. It installs over the original pack. This is an add-on, not a standalone modpack or a conventional resource pack. Compatibility has only been checked for Cube Warper 1.15; other pack versions have not been tested.

## Included translations

- The complete quest book.
- The complete Clanging Howl language file.
- Additional pack-specific text: hints, menus, the ritual guide and credits.
- Around 2300 previously untranslated block, item and entity names across multiple mods.
- The AE2 guide, together with the ExtendedAE, Applied Flux, ae2wtlib and ME Requester guides. Hold G while hovering over an item to open it.

Where Cube Warper changes AE2 recipes, the guide explains how the item is actually made in this pack, including the Thermal crystallizer and press and the Create deployer.

The included Cube-Warper-RU-fixes resource pack corrects Russian AE2 and add-on names and hides guide pages about mods that are not present in Cube Warper.

## Installation

1. Install the original Cube Warper 1.15 modpack.
2. Extract ALL contents of the localization archive into the instance root, allowing files to be replaced. Install the entire archive: it includes the configuration files that enable the resource pack as well as the other translation files.
3. Select Russian in the game language settings.

## If the instance has already been launched

Open Options → Resource Packs. Make sure Cube-Warper-RU-fixes is enabled and appears ABOVE AETexturesBackport. If it is not enabled, move it into the selected list manually and place it above AETexturesBackport.

The pack also binds G to the Curios menu by default. The localization removes that binding for new instances. For an instance that has already been launched, unbind it manually under Options → Controls → Curios → Open/Close Curios Inventory. Holding G over an item will then open the AE2 guide.

## Limitations and feedback

Some mod strings may still appear in English. AE2 guide pages about mods that are not installed in this pack were not translated and are hidden. In-game testing is ongoing.

When reporting a problem, please include a screenshot, the item or quest name and the localization revision. Current release: r18.
